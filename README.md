#  HH Goa 2026 — Builder ID Generator

A creative and interactive **HH Goa 2026 Builder ID Generator** that lets users create a personalized event-style Builder ID using their photo, name, role, and a custom builder title.

Built with **pure HTML, CSS and Vanilla JavaScript** — no frameworks, no backend, no login.

---

##  Features

*  Upload your profile photo
*  Enter your name and stack/role
*  Choose from multiple Builder Title suggestions
*  Generate a random Builder Title
*  Real-time Builder ID preview
*  Fully responsive mobile-first layout
*  Download your Builder ID as PNG
*  Share to X with a pre-filled caption
*  No login or signup required
*  Works entirely in the browser


##  Tech Stack

* **HTML5**
* **CSS3**
* **Vanilla JavaScript**
* **HTML5 Canvas API**
* **FileReader API**
* **Blob & URL APIs**
* **Google Fonts**

No React, Vue, Angular, Bootstrap or Tailwind.


##  How It Works

```text
Upload Photo
     ↓
Enter Name
     ↓
Enter Stack / Role
     ↓
Choose Builder Title
     ↓
Live Builder ID Preview
     ↓
Generate High-Resolution PNG
     ↓
Download / Share to X
```
